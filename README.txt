VEROEFFENTLICHUNG
1. Den gesamten Inhalt dieses Ordners unveraendert auf einen HTTPS-Webspace hochladen.
2. index.html ueber die HTTPS-Adresse aufrufen.
3. iPhone: In Safari Teilen > Zum Home-Bildschirm.
4. Android: Im Browser App installieren oder Zum Startbildschirm hinzufuegen.

WICHTIG
- Eine PWA funktioniert nicht vollstaendig direkt aus der Dateien-App.
- Service Worker und Offline-Modus benoetigen eine Bereitstellung ueber HTTPS oder localhost.
- Tagesumsatz, Bestellungen und Pfandrueckzahlungen werden lokal auf dem jeweiligen Geraet gespeichert.
- Mehrere Handys synchronisieren ihre Tageswerte nicht miteinander.
